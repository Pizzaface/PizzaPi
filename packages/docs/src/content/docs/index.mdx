PizzaPi packages the `pi` coding agent with a relay-connected web interface. The agent runs on your machine; the relay streams session events to a browser and supports remote session management. A relay is optional for terminal-only use.

## Choose a path

- **New install:** [Install PizzaPi](/PizzaPi/start-here/installation/), then follow [Your first working session](/PizzaPi/start-here/getting-started/).
- **Use an existing relay:** run `pizzapi setup`, connect to the relay address, then launch `pizzapi` in a project directory.
- **Local relay:** with Docker available, run `pizzapi local` to start the relay and foreground runner.
- **Terminal only:** run `PIZZAPI_RELAY_URL=off pizzapi` without setting up a relay.

## Understand the components

| Component | Runs where | Role |
|---|---|---|
| `pizzapi` CLI / runner | Your development machine or container | Runs the agent and its tools. |
| Relay server | Local or hosted machine | Authenticates clients and relays session events. |
| Web UI | Browser, served by relay | Views sessions, sends messages, manages runners. |

The runner connects outward to the relay; the relay does not need an inbound connection to your development machine. See [Architecture](/PizzaPi/reference/architecture/) for communication details.
